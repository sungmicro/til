# 예시 자료

프로그램 검증용 자료다. **실명은 담지 않는다** — 분석자는 A~E 로 익명화한다.

실명 대응표는 저장소에 넣지 말고 랩 내부 기록으로만 관리할 것.
비교숙련도 결과는 개인 업무 평가로 읽힐 수 있는 자료이므로,
공개 저장소에 실명과 함께 올리면 안 된다.

| 파일 | 내용 |
|---|---|
| `antibacterial_R_ecoli.csv`   | ISO 22196, 대장균 *E. coli*, 분석자 5명 × 6개 R 값 |
| `antibacterial_R_saureus.csv` | ISO 22196, 황색포도상구균 *S. aureus*, 분석자 5명 × 6개 R 값 |
